# Obsidian Notes

## Recommended settings

- Use this repository as your Obsidian vault.
- Enable graph view and backlinks.
- Install Obsidian Web Clipper if you want to capture articles into markdown quickly. Karpathy explicitly recommends Obsidian Web Clipper, and the tutorial includes an installation step for it. [page:1][web:1]
- Consider Dataview if you plan to use YAML frontmatter for dynamic indexes and tables. Karpathy mentions Dataview as a useful optional plugin when the LLM adds frontmatter such as tags, dates, and source counts. [page:1]

## Suggested habits

- Keep `sources/` read-only in spirit. Raw documents are the source of truth and should not be rewritten by the LLM. [page:1]
- Browse `wiki/index.md` first when you want a map of the vault. Karpathy describes the index as the main catalog for pages and summaries. [page:1]
- Use `wiki/log.md` to track chronology and maintenance history. [page:1]
- Use graph view to find hubs and orphans. Karpathy highlights Obsidian's graph view as a strong way to see the shape of the wiki. [page:1]

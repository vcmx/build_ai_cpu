### Setting up Markitdown
The source of the instructions and codes is from https://www.youtube.com/watch?v=UFEVQdJeWeQ

## Downloading the packages

uv pip install markitdown[all]

## Get into the environment
- get into folder "convert"
- run:

'''bash'''
    .venv\Scripts\activate
    uv run markitdown .\raw\[name of source file].pdf > [name of output file].md
'''

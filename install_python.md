# Install Python for Windows
1. **Check if Python is installed**. Open PowerShell in Administrator mode and run:
```
python --version
```
2. **Download Python**. If Python is not present, open browser and go to [python.org/downloads/windows/](https://www.python.org/downloads/windows/).
3. Scroll down the page and look for "Download Python Install Manager" and run the installer.
4. Accept default options and finish the installation.
5. Confirm that Python is installed using Step 1.
